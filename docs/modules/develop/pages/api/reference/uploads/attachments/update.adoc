= Update Attachments

==  Input attributes

When you want to update a Decidim attachment's details, you need to rely on the `AttachmentAttributes` type, which has the following input fields.

[source]
----
• collection            (optional) - Integer
• description           (optional) - JSON
• file                  (Required) - JSON - FileInputObject format
• title                 (Required) - JSON
• weight                (Optional) - Integer
----

== Sample request

The `UpdateAttachment` mutation allows authenticated administrators to update attachments within certain resources. This mutation uses the existing `UpdateAttachment` command from the admin controller. In the below example, we are updating an attachment bound to a `Result` type.

[source,graphql]
----
mutation updateAttachmentMutation($componentId: ID!, $resultId: ID!, $input: UpdateAttachmentInput!) {
  component(id: $componentId) {
    ... on AccountabilityMutation {
      result(id: $resultId) {
        updateAttachment(input: $input) {
          id
          title {
            translation(locale: "en")
          }
          description {
            translation(locale: "en")
          }
        }
      }
    }
  }
}
----
