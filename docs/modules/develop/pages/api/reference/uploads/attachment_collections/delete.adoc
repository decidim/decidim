= Delete Attachment Collections

== Sample request

The `deteteAttachment` mutation allows authenticated administrators to delete any attachment collections.

[source,graphql]
----
mutation deleteAttachmentCollection($componentId: ID!, $resultId: ID!, $attachmentCollectionId: ID!){
  component(id: $componentId){
    ... on AccountabilityMutation {
      result(id: $resultId){
        deleteAttachmentCollection(id: $attachmentId){
          id
        }
      }
    }
  }
}
----

Example of submitted variables

[source,json]
----
{
  "componentId": "3",
  "resultId": "5",
  "attachmentCollectionId": "1234"
}
----
