= API file upload handling

Files are attached to records in the same request which creates or updates the
attachment: the `file` input field of `AttachmentAttributes` is an upload, so the
file has to be sent as `multipart/form-data` following the
https://github.com/jaydenseric/graphql-multipart-request-spec[GraphQL multipart
request spec].

The file variable must be `null` in the `operations` payload and the uploaded
file is mapped separately:

[source,bash]
----
curl -X POST https://example.org/api/ \
  -F 'operations={"query":"mutation ($input: CreateAttachmentInput!) { createAttachment(input: $input) { id } }","variables":{"input":{"attributes":{"file":null}}}}' \
  -F 'map={"0":["variables.input.attributes.file"]}' \
  -F '0=@/path/to/file.jpg'
----

The file is validated before it is stored, and the attachment record is created
from it. A file which does not pass the checks is rejected with a validation
error and the blob is not stored.
