= Delete Blobs

== Sample request

The `deleteBlob` mutation allows authenticated administrators to delete upload blobs attached to records of their own organization.
Blobs attached to records of other organizations (or shared with them) cannot be deleted.

Blobs which are not attached to any record cannot be deleted with this mutation. A blob does not belong to an organization by itself, its ownership is derived from the records it is attached to, so an unattached blob (for instance one created by xref:develop:api/reference/uploads/blobs/upload.adoc[uploadFile] and never used by an attachment) cannot be attributed to the requesting organization. These blobs are rejected with a `VALIDATION_ERROR`; they are removed by the xref:install:index.adoc#scheduled_tasks[scheduled cleanup task] (`rake decidim:attachments_cleanup`, hourly by default), which purges unattached blobs older than the configured window.

[source,graphql]
----
mutation deleteBlob($blobId: ID!){
  deleteBlob(id: $blobId){
    id
  }
}
----

Example of submitted variables

[source,json]
----
{
  "blobId": "3"
}
----

== Error Handling

The most frequent errors that can be generated by this mutation are as follows:

* xref:develop:api/reference/errors/unauthorized_mutation.adoc[Unauthorized Mutation Error - MUTATION_NOT_AUTHORIZED_ERROR]
* xref:develop:api/reference/errors/unauthorized_field.adoc[Unauthorized Field Error - UNAUTHORIZED_FIELD_ERROR]
* xref:develop:api/reference/errors/not_found.adoc[Not Found Error - NOT_FOUND_ERROR]
* xref:develop:api/reference/errors/validation_error.adoc[Attribute Error - VALIDATION_ERROR] - when the blob is not attached to any record
