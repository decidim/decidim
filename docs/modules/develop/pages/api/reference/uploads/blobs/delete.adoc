= Delete Blobs

== Sample request

The `deleteBlob` mutation allows authenticated administrators to delete any upload blobs.

[source,graphql]
----
mutation deleteBlob($blobId: ID!){
  deleteBlob(id: $blobId){
    id
  }
}
----

Example of submitted variables

[source,json]
----
{
  "blobId": "3"
}
----
